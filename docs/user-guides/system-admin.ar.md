# دليل المستخدم — مدير النظام (System Admin)

> النسخة الإنجليزية: [`system-admin.en.md`](system-admin.en.md) · آخر تحديث: نهاية الأسبوع 3

مدير النظام هو المستخدم صاحب التحكم الكامل **داخل شركة واحدة** (Tenant). مبيقدرش يدير المنتج نفسه أو شركات تانية (ده دور Super Admin المنفصل).

**قاعدة ثابتة:** فيه **مدير نظام واحد فقط لكل شركة**. النظام بيرفض إنشاء تاني، وبيرفض تعطيل حساب مدير النظام دايمًا (حتى لو هو اللي بيحاول).

---

## 1. تسجيل الدخول

- الرابط: `/login`
- بالبريد الإلكتروني وكلمة السر.
- مفيش تغيير لكلمة السر من الملف الشخصي لموظفي GCM والسائقين (حسب الـFRD) — لو نسيتها استخدم **Forgot Password** في صفحة الدخول. البريد الإلكتروني **ثابت** ومبيتغيّرش بعد الإنشاء.

## 2. لوحة التحكم (Dashboard)

- بتظهر بعد الدخول مباشرة، وفيها اسمك ودورك واسم شركتك بوضوح ("مدير النظام — GCM").
- **حاليًا شاشة تمهيدية بس** — الإحصائيات التفصيلية بتيجي في الأسبوع 8.

## 3. الملف الشخصي

- من قائمة الحساب في الشريط العلوي → **My Profile**.
- **تغيير الصورة الشخصية وكلمة السر** (تاب "Security" — بتكتب كلمة السر الحالية الأول). الاسم والبريد معروضين للقراءة.

## 4. إدارة المستخدمين — `/app/user/list`

الشاشة الوحيدة اللي مدير النظام بس بيشوفها من الأدوار التينانت.

### قائمة المستخدمين
- جدول بـ 7 أعمدة: الرقم التعريفي (`code`) / المستخدم / التبعية / الجهة / الدور / الحالة / إجراءات.
- **الترقيم والفرز والبحث كلهم من السيرفر** — بيشتغل بكفاءة حتى مع آلاف المستخدمين.
- البحث بيلاقي بالاسم أو البريد أو الرقم التعريفي.
- فلاتر: الدور (data_entry / auditor / driver) + الحالة (نشط / في إجازة / معطّل).
- زر **تصدير** (Excel / PDF).

### زر "إضافة مستخدم" — قائمة منسدلة
- **GCM Staff (مدخل بيانات / مدقق)** → فورم إنشاء مستخدم عادي.
- **سائق** → بيوديك لصفحة إنشاء السائق المخصصة (`/app/driver/add`) — مش نفس الفورم.
- *(خيارات "عميل" و"متعهد" هتتضاف في الأسبوع 4–5.)*

### إنشاء مستخدم GCM
- الحقول: الاسم، البريد، رقم الموبايل، الصورة (اختياري)، كلمة السر، الحالة، الدور (data_entry أو auditor فقط — مش system_admin ولا driver)، بيانات إضافية (اختياري).
- **مينفعش تنشئ مدير نظام تاني** — الخيار مش موجود، ولو حد حاول يبعت الطلب مباشرة بيترفض.

### عرض / تعديل مستخدم
- صفحة تفاصيل + صفحة تعديل منفصلتين.
- **كلمة سر جديدة (اختياري):** في صفحة التعديل تقدر تحط كلمة سر جديدة + تأكيد لأي مستخدم أو سائق — سيبها فاضية لو مش عايز تغيّرها. ودي الطريقة اللي بتحط بيها كلمة سر لحد تاني (كل مستخدم يقدر كمان يغيّر كلمة سره بنفسه من الملف الشخصي).
- لو المستخدم ده سائق، صفحة التعديل بتوريك رسالة وبتوجّهك لصفحة تعديل السائق (لأن بيانات السائق — إقامة/رخصة/تأمين — بتتعدّل هناك).
- **البيانات الإضافية الفاضية مبتظهرش** كعنوان فاضي في صفحة التفاصيل.

### تغيير حالة المستخدم
- نشط / في إجازة / معطّل — من صفحة التفاصيل.
- **تعطيل مدير نظام ممنوع دايمًا.**

## 5. إدارة المركبات — `/app/vehicle/list`

مدير النظام عنده **صلاحية كاملة**: عرض، إنشاء، تعديل، تصدير، وكل تغييرات الحالة (بما فيها التعطيل والتنشيط-من-معطّل).

### القائمة
- كروت إحصائية: متاح / في رحلة (0 حاليًا — بييجي مع موديول الرحلات) / في الصيانة / معطّل، وكروت حسب الفئة (**كارت لكل تصنيف موجود عندك فعلًا** — مش رقم ثابت).
- جدول server-side كامل: هوية المركبة = **اللوحة** (مفيش `code`). البحث بيلاقي حتى لو كتبت اللوحة كاملة بالمسافة (`AAA 1234`).
- فلاتر: الفئة / الحالة التشغيلية / التبعية. زر تصدير (Excel / PDF).
- زر **إضافة مركبة**.

### إنشاء / تعديل مركبة
- بيانات أساسية: اللوحة (حروف + أرقام، أرقام فقط)، الفئة، التبعية، هل فيها حاوية مدمجة (لو نعم: نوعها + سعتها — القائمة بتتفلتر حسب المتاح في مجمع الأصول).
- صور (أمامية/خلفية) + وثائق (رخصة السير / الفحص الفني / شهادة الفحص / التأمين) بأرقام وتواريخ صلاحية.
- تصاريح دخول متكررة (منطقة / رقم / صلاحية / مرفق).
- **كل أرقام الوثائق والتصاريح أرقام فقط.**

### تصنيفات المركبات — Vehicles ← Categories (`/app/vehicle-category/list`) — مدير النظام فقط
- الشركة بتبدأ بالـ6 تصنيفات الافتراضية، وتقدر **تضيف تصنيفات جديدة** وتعدّل أسماء أي تصنيف (اسم إنجليزي + اسم عربي، كل واحد فريد جوه شركتك).
- **الحذف ممنوع لو التصنيف مربوط** بمركبات أو بسائقين (أنواع مؤهلين لقيادتها) أو بأصول (تصنيف متوافق) — أيقونة الحذف بتبقى مقفولة، والرسالة بتقولك مربوط بإيه (مثلاً "3 مركبات، 1 أصل"). الستة تصنيفات **الأساسية** (الخمسة بتوع الـFRD + شاحنة جرّارة) تقدر تغيّر اسمهم لكن **مايتمسحوش أبدًا** حتى لو مش مربوطين بحاجة (أيقونة الحذف عليهم مقفولة دايمًا). اللي يتمسح هو التصنيف اللي إنت ضفته بنفسك، وبس وهو مش مربوط.
- أي تصنيف جديد بيظهر تلقائيًا كارت في صفحة المركبات، وفي فلتر الفئة، وفي فورمات المركبة والسائق والأصل. وتعديل الاسم بيتغير في كل حتة (المركبات المرتبطة بيه بتفضل مرتبطة).
- زر **Export** (Excel / PDF) في القائمة — الملف بيحتوي الصفوف المطابقة لمربع البحث.
- لينك "Manage categories" فوق كروت التصنيفات في صفحة المركبات بيوديك على نفس الصفحة.

### حالة المركبة
- **مدير النظام**: "في الصيانة" + **تعطيل** + **تنشيط من معطّل**.

## 6. إدارة السائقين — `/app/driver/list`

مدير النظام بس. **إنشاء وتعديل السائق حصريًا من هنا** — مش من فورم المستخدمين.

### القائمة
- 4 كروت إحصائية: المتاحين / في رحلات (0 حاليًا) / في إجازة / المعطّلين.
- جدول بـ 5 أعمدة: الرقم التعريفي / اسم السائق / التبعية / توفر السائق / تفاصيل.
- فلاتر: التبعية (GCM / متعهد) + توفر السائق. زر تصدير.
- زر **إنشاء مستخدم جديد سائق**.

### إنشاء سائق (صفحة واحدة، بتنشئ كل حاجة مع بعض)
1. **بيانات الحساب:** الاسم، البريد، الموبايل، الصورة، كلمة السر، الحالة، بيانات إضافية.
2. **المركبة الافتراضية:** تختار نوع/أنواع المركبات المؤهل لقيادتها (من تصنيفات المركبات الموجودة عندك) + المركبة الافتراضية نفسها (القائمة بتتفلتر حسب الأنواع المختارة، والمركبة لازم تتبع أحد الأنواع دي).
   - **مركبة واحدة لسائق واحد فقط** كمركبة افتراضية — المركبات المأخوذة مش بتظهر في القائمة أصلًا.
3. **الإقامة / رخصة القيادة / رخصة التشغيل / التأمين:** رقم + تاريخ صلاحية + مرفق لكل واحدة.
4. **تصاريح دخول الشاحنة:** متكررة (منطقة / رقم / صلاحية / مرفق) — بزر "إضافة تصريح".

> **مستندات السائق (إقامة/رخص/تأمين/تصاريح) بتتخزن بشكل خاص** — بتترجع بس عن طريق رابط محمي، مفيش رابط عام لها.

### عرض / تعديل سائق
- صفحة تفاصيل فيها كروت لكل مستند + "المركبة الافتراضية".
- صفحة تعديل بنفس الأقسام.

## 7. إدارة الأصول — `/app/asset/list`

مدير النظام: عرض، إنشاء، تعديل (بيانات كاملة)، تصدير، وكل تغييرات الحالة.

### القائمة
- كروت إحصائية **منفصلة للحاويات والصهاريج**: متاح / في مشاريع (0 حاليًا) / في الصيانة / معطّل.
- جدول server-side. فلاتر: النوع (حاوية / صهريج) + الحالة + التبعية. زر تصدير.
- بندين في القائمة الجانبية تحت "Assets": **List** + **Categories**.

### إنشاء أصل
- الاسم، النوع (حاوية / صهريج)، تصنيف السعة (بيتفلتر حسب النوع)، تصنيفات المركبات المتوافقة (checkbox، per-asset)، الحالة، التبعية، تاريخ الشراء، بيانات إضافية.

### تعديل أصل
- **الاسم فقط** قابل للتعديل — السعة والتصنيف مقفولين بعد الإنشاء (قرار من الـ FRD: بيأثروا على التعاقدات والرحلات).

### تصنيفات سعة الأصول — `/app/asset-category/list`
- إنشاء وتعديل. بعد الإنشاء **الاسم فقط** قابل للتعديل (السعة والنوعية مقفولين). مفيش حذف ولا تعطيل.
- أيقونة العين في الجدول بتفتح **صفحة تفاصيل** (إضافة بطلب العميل، مش في الـFRD): بيانات التصنيف نفسه + جدول بكل الأصول اللي عليها التصنيف ده، وكل صف بيودّي لتفاصيل الأصل.

## 8. تغيير حالة أصل
- **مدير النظام**: "في الصيانة" + **تعطيل** + **تنشيط من معطّل**.

## 9. المميزات المتاحة حاليًا (نهاية الأسبوع 3)

| الموديول | متاح | مؤجّل |
|---|---|---|
| المستخدمون | CRUD كامل + حالة + تصدير | خيارات "عميل"/"متعهد" في زر الإضافة (أسبوع 4–5) |
| المركبات | CRUD كامل + حالة + تصدير + الحاوية المدمجة | عمود/عدّاد "في رحلة" + سجل رحلات المركبة (أسبوع 7) |
| السائقون | CRUD كامل + المركبة الافتراضية + المستندات + التصاريح | حالة "في رحلة" (أسبوع 7)، تطبيق الموبايل |
| الأصول | CRUD كامل + التصنيفات + الحالة + تصدير | "إدراج أصل في مشروع" + عدّاد "في مشاريع" (أسبوع 4) |
| لوحة التحكم | شاشة تمهيدية | إحصائيات حقيقية (أسبوع 8) |
