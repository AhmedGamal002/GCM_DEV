# دليل المستخدم — مدقق (Auditor)

> النسخة الإنجليزية: [`auditor.en.md`](auditor.en.md) · آخر تحديث: مراجعة FRD V01.14

المدقق دور **قراءة فقط** على كل صفحات النظام: يعرض ويصدّر، ومبيعدّلش أي حاجة (لا إنشاء ولا تعديل ولا تغيير حالة). الاستثناء الوحيد: يقدر يغيّر **كلمة سره الشخصية** من الملف الشخصي.

---

## ما تراه في القائمة الجانبية

Dashboard، وعنوان **الحسابات** (Users · Drivers)، وعنوان **الأسطول والأصول** (Vehicles · Assets مع Categories)، وعنوان **العمليات** (Facilities)، وعنوان **العملاء والمشروعات** (Client Companies). أي رابط تاني مش ظاهر — والوصول اليدوي بيرجّع "لا تملك صلاحية عرض هذه البيانات".

## 1. تسجيل الدخول والملف الشخصي

- `/login` بالبريد وكلمة السر.
- **My Profile**: تغيير الصورة الشخصية، **وكمان كلمة السر** (تاب "Security" — بتكتب كلمة السر الحالية الأول). الاسم والبريد للقراءة فقط.

## 2. المستخدمين — `/app/user/list`

- **عرض** قائمة مستخدمي GCM + **تصدير** (Excel / PDF).
- **عرض تفاصيل** أي حساب.
- **ممنوع:** زر "Add User" مش هيفتح فورم شغّال، ومفيش أزرار تعديل أو تغيير حالة.

## 3. السائقين — `/app/driver/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + الفلاتر + **تصدير**.
- **عرض تفاصيل** أي سائق (بياناته، مستنداته، تصاريحه).
- **ممنوع:** أي إنشاء أو تعديل.

## 4. المركبات — `/app/vehicle/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + كل الفلاتر (فئة / حالة / تبعية) + البحث.
- **عرض تفاصيل** أي مركبة (بياناتها، صورها، وثائقها، تصاريحها).
- **تصدير** القائمة (Excel / PDF) — بنفس الفلاتر المطبّقة.
- **ممنوع:** زر "إضافة مركبة" مش موجود، ومفيش أزرار تعديل أو تغيير حالة.

## 5. الأصول — `/app/asset/list`

- **عرض** القائمة + الكروت (حاويات وصهاريج) + الفلاتر + **تصدير**.
- **عرض تفاصيل** أي أصل (وحالته "في مشروع" واسم المشروع لو مدرج في واحد).
- **تصنيفات سعة الأصول** (`/app/asset-category/list`): عرض وتصدير فقط — مفيش إنشاء ولا تعديل. أيقونة العين بتفتح **صفحة تفاصيل** (إضافة بطلب العميل) فيها جدول الأصول اللي عليها التصنيف.
- **ممنوع:** أي إنشاء أو تعديل أو تغيير حالة.

## 6. المنشآت الوسيطة — `/app/facility/list`

- **عرض** القائمة (وفيها الرقم التعريفي لكل منشأة) + الكروت الإحصائية + البحث + الفلاتر + **التصدير**، و**تفاصيل** أي منشأة (وتحميل مرفق العقد).
- **ممنوع:** زر "إنشاء منشأة جديدة" وأيقونة التعديل وكارت الحالة مش بيظهروا، وأي إنشاء / تعديل / تغيير حالة بيرجّع 403.

## 7. شركات العملاء — `/app/company/list`

- **عرض** القائمة + الفلتر + **تصدير**، و**عرض تفاصيل** أي شركة وتنزيل مرفقاتها.
- **ممنوع:** أي إنشاء أو تعديل أو تعطيل (وزر "Add" مش ظاهر في القائمة الجانبية).

## 8. مشروعات العملاء — `/app/project/list`

- **عرض** القائمة (بحث + فلتر الشركة والحالة) + **تصدير**، و**عرض تفاصيل** أي مشروع (وجدول أصوله وتصديره).
- **ممنوع:** أي إنشاء أو تعديل أو تعطيل، وزر "Add" وأيقونة التعديل وزر "إدراج أصل في مشروع" مش ظاهرين.

## 9. اللي مينفعش تعمله (بيرجع 403)

- إنشاء أو تعديل أو تعطيل أي مستخدم / سائق / مركبة / أصل / منشأة / شركة / مشروع / تصنيف، أو إدراج أصل في مشروع.
- تعديل الاسم أو البريد في الملف الشخصي.
- إدارة الأدوار والصلاحيات / الشركات (Tenants).

## 10. المميزات المتاحة حاليًا

عرض + تصدير كامل لكل الموديولات المبنية (المستخدمين، السائقين، المركبات، الأصول، المنشآت الوسيطة، شركات العملاء، مشروعات العملاء، والتصنيفات) — كان مقصور على المركبات والأصول بس قبل ترقية الـFRD لـV01.14. تغيير كلمة السر الشخصية شغّال من الملف الشخصي.
