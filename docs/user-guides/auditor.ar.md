# دليل المستخدم — مدقق (Auditor)

> النسخة الإنجليزية: [`auditor.en.md`](auditor.en.md) · آخر تحديث: نهاية الأسبوع 3

المدقق دور **قراءة فقط** على المركبات والأصول: يعرض ويصدّر، ومبيعدّلش أي حاجة. مبيشوفش المستخدمين ولا السائقين.

---

## ما تراه في القائمة الجانبية

3 عناصر: **Dashboard** · **Vehicles** · **Assets** (مع Categories). أي رابط تاني مش ظاهر — والوصول اليدوي بيرجّع "لا تملك صلاحية عرض هذه البيانات".

## 1. تسجيل الدخول والملف الشخصي

- `/login` بالبريد وكلمة السر.
- **My Profile**: تغيير الصورة الشخصية فقط. الاسم وكلمة السر وباقي البيانات بتديرها الإدارة (مدير النظام / مدخل البيانات).

## 2. المركبات — `/app/vehicle/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + كل الفلاتر (فئة / حالة / تبعية) + البحث.
- **عرض تفاصيل** أي مركبة (بياناتها، صورها، وثائقها، تصاريحها).
- **تصدير** القائمة (Excel / PDF) — بنفس الفلاتر المطبّقة.
- **ممنوع:** زر "إضافة مركبة" مش موجود، ومفيش أزرار تعديل أو تغيير حالة.

## 3. الأصول — `/app/asset/list`

- **عرض** القائمة + الكروت (حاويات وصهاريج) + الفلاتر + **تصدير**.
- **عرض تفاصيل** أي أصل.
- **تصنيفات سعة الأصول** (`/app/asset-category/list`): عرض وتصدير فقط — مفيش إنشاء ولا تعديل.
- **ممنوع:** أي إنشاء أو تعديل أو تغيير حالة.

## 4. اللي مينفعش تعمله (بيرجع 403)

- إنشاء أو تعديل أو تعطيل أي مركبة / أصل / تصنيف.
- إدارة المستخدمين أو السائقين (كل شيء).
- إدارة الأدوار والصلاحيات / الشركات.

## 5. المميزات المتاحة حاليًا (نهاية الأسبوع 3)

عرض + تصدير كامل للمركبات والأصول والتصنيفات. أي شيء أبعد من العرض/التصدير خارج نطاق هذا الدور بالكامل.
