# دليل المستخدم — مدقق (Auditor)

> النسخة الإنجليزية: [`auditor.en.md`](auditor.en.md) · آخر تحديث: مراجعة FRD V01.14

المدقق دور **قراءة فقط** على كل صفحات النظام: يعرض ويصدّر، ومبيعدّلش أي حاجة (لا إنشاء ولا تعديل ولا تغيير حالة). الاستثناء الوحيد: يقدر يغيّر **كلمة سره الشخصية** من الملف الشخصي.

---

## ما تراه في القائمة الجانبية

Dashboard، وعنوان **الحسابات** (Users · Drivers)، وعنوان **الأسطول والأصول** (Vehicles · Assets مع Capacities)، وعنوان **العمليات** (Facilities · Services · Contractors — القوائم بس، من غير "Add")، وعنوان **العملاء والمشروعات** (Client Companies). أي رابط تاني مش ظاهر — والوصول اليدوي بيرجّع "لا تملك صلاحية عرض هذه البيانات".

## 1. تسجيل الدخول والملف الشخصي

- `/login` بالبريد وكلمة السر.
- **My Profile**: تغيير الصورة الشخصية، **وكمان كلمة السر** (تاب "Security" — بتكتب كلمة السر الحالية الأول). وتقدر كمان ترفع **صورة التوقيع وصورة الختم التشغيلي** بتوعك (اختياريين، PNG/JPG، حد أقصى 2 ميجا). الاسم والبريد للقراءة فقط.

## 2. المستخدمين — `/app/user/list`

- **عرض** قائمة مستخدمي GCM + **تصدير** (Excel / PDF).
- **عرض تفاصيل** أي حساب — بما فيها حسابات العملاء (الشركة، المشروعات، صورتي التوقيع والختم) ومستخدمو المتعهدين (المتعهد التابع له).
- **ممنوع:** زر "Add User" مش هيفتح فورم شغّال، ومفيش أزرار تعديل أو تغيير حالة.

## 3. السائقين — `/app/driver/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + الفلاتر + **تصدير**.
- **عرض تفاصيل** أي سائق (بياناته، مستنداته، تصاريحه).
- **ممنوع:** أي إنشاء أو تعديل.

## 4. المركبات — `/app/vehicle/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + كل الفلاتر (فئة / حالة / تبعية) + البحث.
- **عرض تفاصيل** أي مركبة (بياناتها، صورها، وثائقها، تصاريحها).
- **تصدير** القائمة (Excel / PDF) — بنفس الفلاتر المطبّقة.
- **ممنوع:** زر "إضافة مركبة" مش موجود، ومفيش أزرار تعديل أو تغيير حالة.

## 5. الأصول — `/app/asset/list`

- **عرض** القائمة + الكروت (حاويات وصهاريج) + الفلاتر + **تصدير**.
- **عرض تفاصيل** أي أصل (وحالته "في مشروع" واسم المشروع لو مدرج في واحد).
- **سعات الأصول** (`/app/asset-category/list`): عرض وتصدير فقط — مفيش إنشاء ولا تعديل. أيقونة العين بتفتح **صفحة تفاصيل** (إضافة بطلب العميل) فيها جدول الأصول اللي عليها السعة.
- **ممنوع:** أي إنشاء أو تعديل أو تغيير حالة.

## 6. المنشآت الوسيطة — `/app/facility/list`

- **عرض** القائمة (وفيها الرقم التعريفي لكل منشأة) + الكروت الإحصائية + البحث + الفلاتر + **التصدير**، و**تفاصيل** أي منشأة (وتحميل مرفق العقد).
- **ممنوع:** زر "إنشاء منشأة جديدة" وأيقونة التعديل وكارت الحالة مش بيظهروا، وأي إنشاء / تعديل / تغيير حالة بيرجّع 403.

## 7. الخدمات — `/app/main-service/list` و`/app/sub-service/list`

- **عرض** قائمة الخدمات الأساسية (بحث + فلاتر النوعية والحالة) + **تصدير**، وصفحة التبويبات للخدمات الفرعية، وتفاصيل أي خدمة أساسية أو فرعية.
- **غير مسموح:** الإنشاء والتعديل والتعطيل — زراير الإنشاء وأيقونات التعديل وزر Edit مش ظاهرين، وأي محاولة عبر الـAPI بترجع 403.

## 8. المتعهدون — `/app/contractor/list`

- **عرض** القائمة (مع كروت الإحصائيات الأربعة) + البحث + الفلتر + **التصدير**، و**تفاصيل** أي متعهد (وتحميل مرفقاته).
- قوائم وتفاصيل السائقين والمركبات والأصول بتعرض اسم المتعهد في عمود التبعية، وبتفلتر بيه.
- **غير مسموح:** الإنشاء أو التعديل أو التعطيل (رابط "Add" مش ظاهر في القائمة الجانبية، وأيقونة / زر التعديل مخفيين).

## 9. شركات العملاء — `/app/company/list`

- **عرض** القائمة + الفلتر + **تصدير**، و**عرض تفاصيل** أي شركة وتنزيل مرفقاتها.
- **ممنوع:** أي إنشاء أو تعديل أو تعطيل (وزر "Add" مش ظاهر في القائمة الجانبية).

## 10. مشروعات العملاء — `/app/project/list`

- **عرض** القائمة (بحث + فلتر الشركة والحالة) + **تصدير**، و**عرض تفاصيل** أي مشروع (وجدول أصوله وتصديره).
- **ممنوع:** أي إنشاء أو تعديل أو تعطيل، وزر "Add" وأيقونة التعديل وزر "إدراج أصل في مشروع" مش ظاهرين.

## 11. التعاقدات — `/app/po/list`

- **عرض** القائمة (الكروت والبحث وفلاتر الشركة والمشروع والمدى الزمني والحالة العامة وحالة الحساب)، و**تفاصيل** أي تعاقد (خدماته وأشرطة المتبقي من كل جزء) و**التصدير** (Excel/PDF)، وتنزيل مرفقه. وصفحتا الشركة والمشروع فيهم كمان قسم **Contracts**.
- **مش مسموح:** الإنشاء والتعديل والتعطيل؛ رابط "Add" وأيقونة التعديل مش ظاهرين.

## 12. الرحلات — `/app/trip/list`

القائمة الجانبية: **Trips** ← List.

- **القائمة:** 5 كروت (في انتظار اعتماد العميل / معتمدة / مرفوضة / مكتملة / ملغاة)، وجدول من الأحدث للأقدم برقم الرحلة والتاريخ والسائق والمركبة وتبعيتهم والعميل والمشروع والخدمة الفرعية والحالة وربط التعاقد؛ فلاتر (المدى الزمني، الحالة، العميل ← المشروع، السائق، المركبة، التبعيات، الخدمة الأساسية ← الفرعية)، وبحث، و**تصدير Excel / PDF** مطابق للشاشة.
- **التفاصيل:** بيانات الرحلة كاملة وسجلها، من غير أي أزرار تنفيذ (عرض فقط).
- **مستندات الرحلة:** الرحلة المكتملة فيها سند التسليم وبيان النفايات (مش لرحلات التوريد) والملف المجمّع PDF.

## 13. الإشعارات — `/app/notifications`

**الجرس** في الشريط العلوي بيظهر نقطة لو فيه حاجة مقروءتش وبيعرض **آخر 5 إشعارات** (النوع والجملة والتاريخ والوقت) كل واحد بيفتح الرحلة (أو التعاقد)؛ وفيه "تحديد الكل كمقروء" و"عرض كل الإشعارات". **صفحة الإشعارات** فيها جدول بكل إشعاراتك (الأحدث أولًا) بفلتر النوع والمدى الزمني وشريط بحث (رقم الرحلة، رقم التعاقد، النوع). إشعارات عادية مش لحظية — بتظهر لما الصفحة تتحمّل أو الجرس يتفتح. بتشوف إشعاراتك إنت بس، ومابيجيلكش إشعار بحاجة إنت عملتها.

المراقب مش من مستلمي الإشعارات (الـFRD ماذكرهوش)، لكن الجرس والصفحة موجودين وبيظهروا فاضيين.

## 14. التقارير — `/app/reports`

القائمة الجانبية: **Reports**. تسع فلاتر — المدى الزمني (اليوم، هذا الأسبوع، هذا الشهر، هذا الربع، هذه السنة، أو مدى مخصص)، شركة العميل، المشروع، الخدمة الفرعية، حالة اعتماد الرحلة، المركبة، السائق، مقاول الباطن، منشأة إعادة التدوير — بتحرّك كل الصفحة مع بعض: الأرقام (الرحلات، النفايات بالطن والمتر المكعب، المركبات المستخدمة، السائقين)، والرسوم (الرحلات خلال الفترة، الرحلات حسب الحالة، الخدمات الفرعية بعدد الرحلات والطن)، وجدول **ملخص الرحلات** وتصديره **Excel** (م، رقم الرحلة، شركة العميل، المشروع، التاريخ، الوقت، رقم مستند التسليم، رقم بيان النفايات، الخدمة الفرعية، سعة الحاوية، حالة الرحلة). أرقام المستندات هي أرقام المستندات المولّدة وبتظهر بعد أول توليد لمستندات الرحلة. الرحلة الملغاة صف في الملخص وبتتحسب في رسم الحالات بس.

## 15. اللي مينفعش تعمله (بيرجع 403)

- إنشاء أو تعديل أو تعطيل أي مستخدم / سائق / مركبة / أصل / منشأة / خدمة / شركة / مشروع / تصنيف، أو إدراج أصل في مشروع.
- تعديل الاسم أو البريد في الملف الشخصي.
- إدارة الأدوار والصلاحيات / الشركات (Tenants).

## 16. المميزات المتاحة حاليًا

عرض + تصدير كامل لكل الموديولات المبنية (المستخدمين، السائقين، المركبات، الأصول، المنشآت الوسيطة، الخدمات الأساسية والفرعية، المتعهدين، شركات العملاء، مشروعات العملاء، التعاقدات، والتصنيفات) — كان مقصور على المركبات والأصول بس قبل ترقية الـFRD لـV01.14. تغيير كلمة السر الشخصية شغّال من الملف الشخصي.
