# دليل المستخدم — سائق (Driver)

> النسخة الإنجليزية: [`driver.en.md`](driver.en.md) · آخر تحديث: نهاية الأسبوع 3

حساب السائق بيتنشئ من مدير النظام (من صفحة السائقين)، وبيشمل بيانات الإقامة والرخص والتأمين وتصاريح الدخول والمركبة الافتراضية.

---

## الوضع الحالي عبر الويب

السائق **مبيستخدمش لوحة التحكم الإدارية** — تطبيق الموبايل بتاعه بييجي في مرحلة لاحقة. لو سجّل دخول على `/login` دلوقتي:

- **يشوف في القائمة الجانبية: عنصر واحد فقط — Dashboard.** (Users / Vehicles / Drivers / Assets وكل سقالة القالب **مخفية**.)
- لو حاول يفتح أي صفحة تانية يدويًا (زي `/app/user/list`) بيرجّع 403 والجدول بيعرض "لا تملك صلاحية عرض هذه البيانات".
- **يقدر يستخدم الملف الشخصي** (My Profile): تغيير صورته الشخصية فقط. الاسم وكلمة السر بيغيّرهم مدير النظام أو مدخل البيانات.
- يقدر يقرأ قائمة الأدوار (بيانات مرجعية) — من غير أي تأثير عملي عليه.

## اللي مينفعش يعمله

- أي وصول لبيانات المركبات أو السائقين أو الأصول أو المستخدمين.
- تعديل بيانات السائق الخاصة به (الإقامة/الرخص/التأمين/المركبة الافتراضية) — دي بتتعدّل من مدير النظام فقط، من صفحة تعديل السائق.
