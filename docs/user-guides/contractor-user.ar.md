# دليل المستخدم — مستخدم المتعهد

> النسخة الإنجليزية: [`contractor-user.en.md`](contractor-user.en.md) · آخر تحديث: FRD V01.14 §6 (صفحات مستخدم المتعهد)

مستخدم المتعهد حساب تابع لـ**شركة متعهد** (مقاول باطن بيدعم GCM بسائقين ومركبات وحاويات). الدور **عرض وتصدير بس** — وبس لسجلات **متعهده هو**. مفيش إنشاء ولا تعديل ولا تغيير حالة لأي حاجة.

---

## إيه اللي بتشوفه في القائمة الجانبية

Dashboard، و**Users**، و**Drivers**، و**Vehicles**، و**Assets** — وتحت كل واحدة **List** بس. مفيش "Add"، ولا التصنيفات/السعات، ولا أي حاجة عن متعهدين تانيين أو شركات العملاء أو المشروعات أو المنشآت أو الخدمات.

## 1. الدخول والملف الشخصي

- `/login` بالإيميل وكلمة السر.
- **الملف الشخصي:** تغيّر صورتك وكلمة سرك (بتكتب الحالية الأول). مفيش صورة توقيع/ختم للدور ده.

## 2. المستخدمين — `/app/user/list`

- بتشوف **سائقي متعهدك** و**باقي مستخدمي متعهدك** (حسابك إنت مش بيظهر في القايمة).
- فلتر بالدور (مستخدم متعهد / سائق) وبالحالة، وبحث بالاسم أو الإيميل أو الرقم التعريفي.
- **تصدير** القايمة (Excel / PDF) — الصفوف اللي قدامك بالظبط.
- بتفتح تفاصيل أي حساب منهم؛ حساب خارج متعهدك مبيتفتحش.

## 3. السائقين — `/app/driver/list`

- بتشوف سائقي متعهدك مع كروت الإحصاء (متاح / في إجازة / معطّل) وعمود **حالة الوثائق**.
- تفاصيل السائق: بياناته ووثائقه (الإقامة، الرخصة، الرخصة التشغيلية، التأمين) وتصاريح الدخول بأشرطة الوقت المتبقي.
- **تصدير** القايمة (Excel / PDF).

## 4. المركبات — `/app/vehicle/list`

- بتشوف مركبات متعهدك مع كروت الحالة والتصنيفات، وفلاتر (التصنيف / الحالة / حالة الوثائق) وبحث.
- تفاصيل المركبة: الصور والوثائق وتصاريح الدخول.
- **تصدير** القايمة (Excel / PDF).

## 5. الأصول — `/app/asset/list`

- بتشوف أصول متعهدك (حاويات وصهاريج) مع الكروت وفلاتر (النوع / التوفر) وبحث.
- تفاصيل الأصل (شاملة المشروع اللي هو فيه لو مدرج في مشروع).
- **تصدير** القايمة (Excel / PDF).

---

## اللي ماتقدرش تعمله

- إنشاء أو تعديل أو تغيير حالة أي مستخدم/سائق/مركبة/أصل (مفيش أزرار، والسيرفر بيرفض الطلب).
- تشوف سجلات متعهد تاني، أو سائقين/مركبات/أصول GCM نفسها، أو أي حساب عميل.
- تفتح الإعدادات أو المتعهدين أو الشركات أو المشروعات أو الخدمات أو المنشآت.

## جاي بعدين

- **جدول الرحلات** الخاصة بمستخدميك ومركباتك، وبيانات كل رحلة ومستند التسليم (DN) — مع موديول الرحلات.

## المميزات المتاحة حاليًا

| الميزة | متاحة |
|---|:---:|
| الدخول + الملف الشخصي (صورة، كلمة سر) | ✅ |
| المستخدمين: سائقو ومستخدمو متعهدك (عرض / تصدير) | ✅ |
| السائقين: عرض + وثائق + تصدير | ✅ |
| المركبات: عرض + وثائق + تصدير | ✅ |
| الأصول (حاويات / صهاريج): عرض + تصدير | ✅ |
| الرحلات: الجدول + بيانات الرحلة + DN | — (لاحقًا) |
