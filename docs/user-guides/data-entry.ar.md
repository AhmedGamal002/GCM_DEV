# دليل المستخدم — مدخل البيانات (Data Entry)

> النسخة الإنجليزية: [`data-entry.en.md`](data-entry.en.md) · آخر تحديث: أثناء الأسبوع 3 (مراجعة فجوات الـFRD)

مدخل البيانات مسؤول عن **إنشاء وتعديل بيانات المستخدمين والسائقين والمركبات والأصول**. التعطيل النهائي وإعادة التنشيط منه فقط لمدير النظام في كل الموديولات.

---

## ما تراه في القائمة الجانبية

Dashboard، وبعدها عنوان **الحسابات** (Users · Drivers)، وعنوان **الأسطول والأصول** (Vehicles · Assets — وتحت Assets بند Categories). أي رابط تاني (إدارة الأدوار والصلاحيات، وسقالة القالب الديمو) **مش ظاهر** — ولو فتحته يدويًا هيرجّع "لا تملك صلاحية عرض هذه البيانات".

## 1. تسجيل الدخول والملف الشخصي

- `/login` بالبريد وكلمة السر.
- **My Profile** من الشريط العلوي: تغيير الصورة الشخصية فقط. الاسم وكلمة السر بتديرهم الإدارة — لو نسيت كلمة السر استخدم "Forgot Password" في صفحة الدخول.

## 2. المستخدمين — `/app/user/list`

- **عرض** قائمة مستخدمي GCM (مش السائقين — ليهم صفحة منفصلة) + **تصدير** (Excel / PDF).
- **إنشاء** حساب جديد (مدخل بيانات أو مراقب نظام — مفيش خيار "مدير نظام" هنا خالص).
- **تعديل** بيانات أي حساب (عدا السائقين) — وتقدر تحط **كلمة سر جديدة** (اختياري) من صفحة التعديل. **مقدرش تعدّل حساب مدير النظام** ولا تغيّر حالته (بيرجع 403).
- **الحالة:** تقدر تحوّل الحساب لـ **"في إجازة"** فقط.
  - **متقدرش تعطّل حساب** ولا تنشّط حساب معطّل — ده لمدير النظام فقط.

## 3. السائقين — `/app/driver/list`

- **عرض** القائمة الكاملة + الكروت الإحصائية + الفلاتر (بما فيها التبعية GCM/متعهد) + **تصدير**.
- **إنشاء** سائق جديد (الفورم الكامل: بيانات الحساب + المركبة الافتراضية + إقامة/رخصة/رخصة تشغيلية/تأمين + تصاريح دخول اختيارية).
- **تعديل** بيانات أي سائق — بما فيها **كلمة سر جديدة** (اختياري) من صفحة التعديل.
- **الحالة:** نفس حالة المستخدمين — "في إجازة" فقط، التعطيل لمدير النظام.

## 4. المركبات — `/app/vehicle/list`

> تصنيفات المركبات بيديرها **مدير النظام فقط** (Vehicles ← Categories مش ظاهرة عندك)، لكن التصنيفات بتظهر عندك عادي في الفلتر وفي فورم المركبة.

- **عرض** القائمة الكاملة + الكروت الإحصائية + الفلاتر + **تصدير** (Excel / PDF).
- **إنشاء** مركبة جديدة (نفس الفورم الكامل: بيانات أساسية + صور + وثائق + تصاريح دخول).
- **تعديل** أي مركبة موجودة.
- **الحالة:** تقدر تحوّل المركبة لـ **"في الصيانة"** فقط.
  - **متقدرش تعطّل مركبة** ولا تنشّط مركبة معطّلة — ده لمدير النظام فقط.
- **متقدرش تنشئ مركبة بحالة "معطّل" مباشرة** — الإنشاء دايمًا بحالة نشطة.

## 5. الأصول — `/app/asset/list`

- **عرض** + الكروت الإحصائية (حاويات وصهاريج منفصلين) + الفلاتر + **تصدير**.
- **إنشاء** أصل جديد (الاسم، النوع، تصنيف السعة، تصنيفات المركبات المتوافقة، تاريخ الشراء، ...).
- **تعديل** أصل: **الاسم فقط** — الباقي مقفول بعد الإنشاء.
- **الحالة:** "في الصيانة" فقط (التعطيل/التنشيط لمدير النظام).

### تصنيفات سعة الأصول — `/app/asset-category/list`
- **إنشاء** تصنيف جديد.
- **تعديل:** الاسم فقط (السعة والنوعية مقفولين).
- مفيش حذف ولا تعطيل.

## 6. اللي مينفعش تعمله (بيرجع 403 أو 422)

| | |
|---|---|
| إنشاء حساب "مدير نظام" | ✖ — مفيش الخيار ده أصلاً في الفورم |
| تعطيل / إعادة تنشيط مستخدم أو سائق | ✖ (مدير النظام فقط) |
| تعطيل / تنشيط مركبة أو أصل | ✖ (مدير النظام فقط) |
| إنشاء مركبة/أصل بحالة "معطّل" | ✖ |
| إدارة الأدوار والصلاحيات / الشركات | ✖ |

## 7. المميزات المتاحة حاليًا

المستخدمين والسائقين: عرض/إنشاء/تعديل + حالة "في إجازة" (التعطيل لمدير النظام فقط).
المركبات والأصول: CRUD كامل (عدا التعطيل) + حالة "في الصيانة" + تصدير. الحاوية المدمجة في فورم المركبة شغالة.
مؤجّل: "إدراج أصل في مشروع" (أسبوع 4)، عمود "في رحلة" للمركبات (أسبوع 7).
