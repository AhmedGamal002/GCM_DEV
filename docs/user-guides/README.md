# أدلة المستخدم حسب الدور — User Guides by Role

كل دور في النظام له دليل بنسختين: **عربي (`.ar.md`)** و**إنجليزي (`.en.md`)**. الدليل بيوصف بس المميزات **المتاحة فعليًا دلوقتي** — بيكبر آخر كل أسبوع.

## الأدوار

| الدور | الملف | الوصف المختصر | جهة الدخول |
|---|---|---|---|
| **Super Admin** | `super-admin.{ar,en}.md` | إدارة المنتج نفسه: الشركات (Tenants) والأدوار والصلاحيات العامة | `/platform/login` (منفصلة تمامًا) |
| **مدير النظام** — System Admin | `system-admin.{ar,en}.md` | التحكم الكامل داخل شركة واحدة: مستخدمين، مركبات، سائقين، أصول | `/login` |
| **مدخل البيانات** — Data Entry | `data-entry.{ar,en}.md` | نفس صلاحيات مدير النظام تقريبًا (إنشاء/تعديل/تعطيل) في كل الموديولات — الاستثناء الوحيد: حساب مدير النظام نفسه | `/login` |
| **مدقق** — Auditor | `auditor.{ar,en}.md` | عرض وتصدير كل صفحات النظام (قراءة، بدون تعديل) + تغيير كلمة سره الشخصية | `/login` |
| **سائق** — Driver | `driver.{ar,en}.md` | حاليًا: الملف الشخصي فقط (صورة + كلمة سر) عبر الويب (تطبيق الموبايل لاحقًا) | `/login` |
