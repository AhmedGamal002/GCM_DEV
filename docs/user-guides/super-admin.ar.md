# دليل المستخدم — Super Admin (إدارة المنتج)

> النسخة الإنجليزية: [`super-admin.en.md`](super-admin.en.md) · آخر تحديث: نهاية الأسبوع 3

Super Admin هو مدير **المنتج نفسه** (وليس شركة واحدة). حسابه على **جهة دخول منفصلة تمامًا** ومخزّن في جدول مستقل — مش نفس مستخدمي الشركات.

**مهم:** جلسة Super Admin وجلسة مستخدم الشركة مستقلتين تمامًا في المتصفح — الدخول على واحدة مبيسجّلش خروج من التانية.

---

## 1. تسجيل الدخول

- الرابط: **`/platform/login`** (مش `/login` العادية).
- صفحات Super Admin كلها تحت `/platform/*` وبإنجليزية ثابتة (مش ثنائية اللغة زي صفحات الشركات).

## 2. لوحة تحكم المنتج — `/platform/dashboard`

- شاشة تمهيدية بتأكد إن جلسة الـ platform شغالة صح.

## 3. الشركات (Tenants) — `/platform/tenants`

- **قائمة** بكل الشركات المسجّلة.
- **إنشاء شركة جديدة** (`/platform/tenants/create`): الاسم + الـ slug + الحالة.
- **تعديل** بيانات شركة.
- **تغيير حالة** شركة (نشط / معطّل) — تعطيل الشركة بيمنع كل مستخدميها من الدخول.
- **مفيش حذف فعلي** — الشركات تتعطّل فقط.

## 4. الأدوار والصلاحيات — `/platform/roles` + `/platform/permissions`

- **دي الجهة الوحيدة اللي بتدير الأدوار والصلاحيات** — حتى مدير النظام في الشركة مبيقدرش يعدّلها، هو بس بيسند دور موجود لمستخدم.
- **الأدوار** (`/platform/roles`): إنشاء / تعديل / حذف.
  - **الحذف مقيّد**: مينفعش تحذف دور لسه مربوط بأي مستخدم — بيرجع رسالة رفض واضحة (422).
- **الصلاحيات** (`/platform/permissions`): إنشاء / تعديل / حذف.
  - الصلاحيات مزروعة بنمط `{resource}.{action}` (مثلاً `users.create`). حاليًا بتظهر في شاشة تعديل الدور لكن **الربط الفعلي بالـ Gates تفصيل مستقبلي** — الصلاحية الفعلية دلوقتي بتتحدد بالدور نفسه.

## 5. اللي مينفعش تعمله من هنا

- أي وصول لبيانات شركة معيّنة (مستخدميها، مركباتها، ...) — Super Admin بيدير الشركات كـ**كيانات**، مش محتواها.
- الدخول على أي صفحة `/app/*` تينانتية — بتحوّلك للوجين لأن مفيش عندك جلسة `web`/tenant.
