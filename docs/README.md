## المحتوى

| المجلد | إيه فيه | اللغة |

## بروتوكول التحديث الأسبوعي

**آخر كل أسبوع، بعد ما نتأكد إن مميزات الأسبوع شغالة فعليًا (تستات خضراء + تحقق يدوي):**

1. **`user-guides/`** — يتزاد عليها قسم/أقسام المميزات الجديدة لكل دور متأثر (النسختين عربي وإنجليزي مع بعض)، مع تحديث جدول "المميزات المتاحة حاليًا" في كل ملف.
2. **`acceptance/`** — يتعمل ملف قبول جديد للأسبوع (`week-N-<module>.md`) بنفس شكل الملفات الموجودة: كل بند = خطوة تحقق + النتيجة المتوقعة + مرجع الـ FRD + التست الآلي اللي بيغطيها.
3. **مزامنة الـ FRD** — كل ملف قبول في رأسه سطر "آخر مزامنة مع FRD نسخة ..." — لما تنزل نسخة `.docx` جديدة في جذر المشروع، قارن الأقسام المتغيّرة وحدّث البنود المتأثرة، وحدّث رقم النسخة.

> القاعدة دي مسجّلة كتعليمة مستديمة في `CLAUDE.md` (قسم "اتفاقيات ثابتة") — أي جلسة شغل بتقفل أسبوع لازم تعمل الخطوات دي قبل ما تعتبر الأسبوع مقفول.
